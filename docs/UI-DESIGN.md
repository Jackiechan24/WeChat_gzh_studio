# 公众号排版界面设计规范

参考 [coss/ui](https://coss.com/ui) 的中性色、细边框、轻阴影和组件状态，适配 Obsidian 原生桌面界面。实现使用 Obsidian DOM 辅助方法和 CSS。

## 设计目标

让选择风格、检查文章和复制正文三个动作清楚易找。排版风格通过缩略图表达，工具栏与菜单采用稳定的中性色。文章内容仍由整套排版风格定义。

## 视觉令牌

| 项目 | 规范 | CSS |
| --- | --- | --- |
| 界面字体 | 跟随 Obsidian 的界面字体 | `--font-interface` |
| 主文字 | 跟随宿主主题 | `--wx-ui-text` |
| 次文字 | 用于文件名、说明、分组和统计 | `--wx-ui-secondary` |
| 浮层底色 | 跟随宿主的主背景 | `--wx-ui-surface` |
| 轻底色 | 用于选中卡片和分段控件底座 | `--wx-ui-muted` |
| 边框 | 1px，跟随宿主主题 | `--wx-ui-border` |
| 主操作 | 浅色主题使用深底浅字，深色主题反转 | `--wx-ui-primary`、`--wx-ui-on-primary` |
| 控件圆角 | 8px | `--wx-ui-radius` |
| 浮层圆角 | 12px | 弹窗、菜单 |
| 浮层阴影 | 细接触阴影和低透明度扩散阴影 | `--wx-ui-shadow` |
| 焦点 | 2px 轮廓，外偏移 2px | `--wx-ui-ring` |

正文 UI 使用 13px，标题使用 14px / 600，次级说明使用 11px。间距以 4px 为基础，常用 8、12、16px。字体与文字颜色使用宿主变量，支持浅色和深色主题。

## 工具栏

- 复制正文为唯一实心主按钮，高 40px、最小宽度 120px。
- 风格和结尾按钮高 36px，使用描边和细接触阴影。
- 更多和关闭按钮为 32px 图标按钮，图标 16px。
- 常用控件间距 8px。宽度至少 540px 时在一行排列，窄面板将风格和结尾放到第二行。
- 按钮悬停显示轻底色。焦点显示轮廓，禁用状态降低透明度。
- 图标按钮通过 `aria-label` 提供名称。可见文字按钮使用已有文字说明。

## 六套风格选择

- 默认浮层宽 480px、高度上限 600px，受面板可用高度约束。
- 六张卡片按两列三行排列，始终能直接选择。
- 卡片间距 10px、内边距 8px、圆角 10px。
- 当前项使用深色边框、轻底色和勾选图标，勾选位始终预留。
- 卡片缩略图来自正式正文渲染管线。
- 高度不足时依次收起适用场景、风格说明和缩略图，保留六个名称及选中状态。
- 方向键移动焦点，Enter 或空格选择，Escape 关闭并回到触发按钮。

## 更多菜单与固定结尾

- 更多菜单宽 232px、内边距 4px，菜单项高 32px。
- 文章、风格、设备预览三个分组使用小字号标签和细分隔线。
- 图标、文字和选中标记分别固定占位。
- 手机和 iPad 使用分段控件，选中项呈现单独表面、边框和轻阴影。
- 固定结尾浮层宽 380px，输入框使用 13px 字体、8px 圆角和可见焦点。
- 输入自动保存。复制、导出和切换文章沿用现有保存流程。

## 底部状态

- 统计使用一行次级文字和等宽数字。
- 一般排版提示默认折叠，摘要显示数量，展开后保留完整说明。
- 图片名称使用独立折叠区域。缺失或不支持的图片自动展开。
- 提示使用中性色图标和说明，减少大块警示色。
- 转换失败、图片读取失败等即时错误持续显示，支持用户定位和处理。

## 验证

检查浅色与深色主题、420px 窄面板、宽面板和较矮窗口。六套风格能选择，菜单能键盘操作，关闭浮层能恢复焦点。验证正文复制、图片内嵌与手机、iPad 样机加载。

参考组件来自 [Button](https://coss.com/ui/docs/components/button)、[Menu](https://coss.com/ui/docs/components/menu)、[Alert](https://coss.com/ui/docs/components/alert)。
